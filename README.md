# EduGuide BF

Assistant intelligent d'orientation académique pour les étudiants burkinabè.

## Problème

Les étudiants disposent de peu d'outils simples pour identifier les filières
et compétences correspondant à leur profil.

## Objectif

Créer une application capable de proposer des pistes d'orientation à partir
du niveau d'études, des notes, des intérêts et du projet professionnel.

## État du projet

Phase de cadrage.

## Technologies envisagées

- Python
- Streamlit
- Pandas
- Scikit-learn
- GitHub
